# SimpleWiki RAG Assistant

Навчальний проєкт системи генерації, доповненої пошуком (Retrieval-Augmented Generation, RAG) над підмножиною **Simple English Wikipedia** у межах курсу «Технології розробки гібридних систем штучного інтелекту».

## Сценарій використання
Система призначена для студента або молодого спеціаліста, який швидко вивчає базові концепції з обраної тематики корпусу (Simple English Wikipedia) і потребує лаконічних, перевірених за корпусом пояснень із посиланням на вихідні фрагменти замість загальних довільних міркувань. Користувач вводить запит природною мовою через інтерфейс командного рядка (CLI) та отримує структуровану відповідь із зазначенням джерел або коректну відмову, якщо в корпусі бракує релевантної інформації.

## Базовий технологічний стек
- **Мова програмування:** Python 3.11+
- **Векторне сховище:** Chroma (локальний режим)
- **Модель ембедингів:** `sentence-transformers/all-MiniLM-L6-v2`
- **Модель генерації:** Ollama (`qwen2.5:3b` або `llama3.2:3b`)
- **Джерело даних:** Simple English Wikipedia (`wikimedia/wikipedia`, конфігурація `20231101.simple`, ліцензія CC BY-SA)
